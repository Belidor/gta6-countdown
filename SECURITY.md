# Security policy

GTA VI Countdown is an unofficial fan project. It has no user accounts, no server of its own and no user data. The watch face and the app ask for no permissions and make no network requests. The website is static and uses Google Analytics only if you allow it.

## Report a vulnerability

Please report it privately. Do not open a public issue.

- **GitHub:** [report a vulnerability](https://github.com/Belidor/gta6-countdown/security/advisories/new) with private vulnerability reporting on this repo.
- **Email:** [belidor@icloud.com](mailto:belidor@icloud.com)

Tell me what is wrong, how to reproduce it and which file, page or release it affects. This is a hobby project, so there is no bug bounty. I reply as soon as I can.

## Scope

- The website: https://gta6-garmin.belidor.cc
- The watch face and the app: [`watchface/`](watchface) and [`app/`](app)
- The release files on the [Releases](https://github.com/Belidor/gta6-countdown/releases) page and their `SHA256SUMS.txt`
- The build scripts and the GitHub Actions workflow in this repo

Garmin Connect IQ, GitHub and Google services are out of scope. Report problems in them to their owners.
